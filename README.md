# UK Discount & Voucher Resources

A curated collection of useful UK resources for finding discount codes, voucher offers, student discounts and money-saving opportunities.

## About This Project

This project brings together useful resources for UK shoppers looking for ways to save money when shopping online.

The resources cover areas such as:

* UK discount codes
* Voucher codes
* Student discounts
* Promotional offers
* Online shopping deals
* Money-saving resources

## UK Voucher Website

### Daily Voucher

[Daily Voucher](https://www.dailyvoucher.co.uk/) is a UK-focused voucher website featuring discount codes, promotional offers and deals from popular online stores.

You can browse stores and find available offers across different shopping categories.
